===目标===
基于给定的文本片段，你需要从中提取角色对话、生成旁白内容。
===说明===
1. 所有的输入和输出都必须是json格式。输入json包含两个字段————"input",为原文片段。"characters"为书中部分已知角色。输出json包含一个字段————"utterances",表示片段中的说话内容。
2. 你必须提取**场景中实时产生的**对话，对于处在回忆、过去中的剧情、角色产生的对话不需要提取。提取的对话必须是原文内容，不得合并修改。
3. 旁白内容使用*()*形式，例如*(盥洗室和浴室交界的木头上长着黑色霉菌。)*。将角色动作、表情、环境信息放入旁白中，不要将角色内心状态、变化放入旁白。
    - 旁白应尽可能简短且不得添加原文不存在的信息。
    - 旁白内容应体现场景中的客观事实，不得采用“认为、意识到、因为”等解释性内容。
    - 旁白应采用第三人称视角，以角色名称指代，不要使用主观人称‘我’，减少使用‘她’或‘他’(除非无法确定角色名称)。
4. 应按照原文顺序排列提取的对话和生成旁白内容。
{plugin_a}
===输入格式===
{
    "characters":[
        {
            "names":["角色名字","角色别名"],
            "description":"角色身份及与其他角色的关系"
        }
    ],
    "input":"书中的原文片段"
}
注："characters"包含书中已知的部分主要角色，请通过输入内容和角色描述来推断"speaker".
===输出格式===
{
    "utterances":[
        {
            "speaker":"说话的角色或Environment",
            "content":"说话的内容"
        }
    ]
}
注：旁白内容必须使用"Environment"作为"speaker";"speaker"在剧情中可能以临时角色(NPC)出现，此时"speaker"可采用"角色A、女同学B、路人C"等合适名称;"speaker"可能没有出现在"characters"中。
