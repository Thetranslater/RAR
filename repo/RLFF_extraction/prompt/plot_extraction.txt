===目标===
基于给定的文本片段，你需要从中识别出剧情和角色，以此将整本书的内容划分为多个连续的剧情。
===说明===
1. 所有的输入和输出都以json格式进行。输入json将包含三个字段————"input"为当前待提取chunk，你的输出只能从"input"中的内容进行提取。"previous"为前一chunk的后{k}句话，帮助你判断"input"的开头是否和上一chunk相连。"next"为下一chunk的前{k}句话，帮助你判断"input"结尾是否和下一chunk连接。
    - 当"previous"为空时，"input"为剧情的开头。当"next"为空时，"input"为剧情的结尾。
2. 输出json包含三个字段————"plots"为从"input"片段中提取的剧情起始句和结尾句数组(形如[["start","end"],["start","end"],...])，表示从"input"中提取的剧情。"state"表示剧情是否被当前chunk截断，只能为"truncated"或"finished"。"characters"需要提取剧情当中具有姓名的角色，如无法推断则暂时忽略。
    - "characters[].name"的第一个元素必须是该角色最完整、稳定的正式名称，其余元素为原文中使用的别名或简称。
    - 如果"plots"的第一个剧情被认为是和"previous"剧情关联，则其起始句为null。
    - 如果"plots"的最后一个剧情被认为是和"next"剧情关联，则其尾句为null。
    - "plots"可能为空，说明"input"内容为无法分割的剧情且与前后chunk剧情关联(如果不存在前后chunk时则是剧情的开头或结尾，则必然存在至少一个plot)
3. 'input'可能包含正文无关的标题、版本、作者及翻译等信息、无法显示的插图(在文中可能以‘(插图03)’这样的文字标识)及作者后记等内容。你需要在提取和分析时忽略这些无关内容。
4. 你需要提取剧情在"input"中的第一句和最后一句来标识一个剧情的位置。如果"input"中剧情被截断(比如开头与上一chunk相连或结尾与下一chunk相连)，则可仅输出第一句或最后一句。
5. [ADVISE]剧情的开头*可能*出现在新自然段。
6. 一个剧情应至少包含多个事件。事件被定义为对剧情当中的实体具有状态变化作用的叙事事件。例：人物出现和离开，物体状态的改变(开门、拾起)等。
===输入格式===
{
    "input": "从书中截取的内容片段",
    "previous": "与input原文相连的上一chunk的后{k}句话。如无内容则为空字符串",
    "next": "与input原文相连的下一chunk的前{k}句话。如无内容则为空字符串"
}
===输出格式===
{
    "characters":[
        {
            "name":["角色的名字或别称",..],
            "description"："可推断的角色的身份和与其他角色关系;角色个人的偏好、特征和性格等信息"
        }
    ],
    "plots": [["第一个剧情的起始句", "第一个剧情的尾句"], ["第二个剧情的起始句", "第二个剧情的尾句"],...],
    "state": "truncated"
}
注："plots"中的句子必须是"input"中的原文；"state"只能为"truncated"或"finished"，当为"truncated"时说明plots中最后一个剧情被截断，此时只保留起始句，无需指出尾句；"characters"中的"description"描述从剧情中可推断的有关角色的个人信息(包括身份、与其他角色关系、身高、年龄等)以及角色个人偏好和特征(如爱好、能力、外表、喜欢的事物和食物等)。
