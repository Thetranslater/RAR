===目标===
给定角色描述文本,你需要从中提取信息并形成角色档案，,用于角色扮演提示词。
===说明===
1. 所有的输入和输出都是json格式。输入json包含一个字段————"character",表示单个角色的名字和描述。输出json包含一个字段————"profile",表示根据角色形成的角色档案。
2. 在输入的描述中,你需要剔除重复的信息并保留所有能够体现角色个人特性的信息。
===输入格式===
{
    "character": {
        "names":["名称1","名称2", ...],
        "description":"角色描述片段"
    }
}
注:"names"表示该角色在书中出现的所有名称和别名。
===输出格式===
{
    "profile": {
        "name":"正式名称",
        "content":"经过总结的角色档案"
    }
}
注:"name"为你从"character.names"中选择的最有可能的角色正式名称。
