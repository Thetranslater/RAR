===目标===
给定输入{manga_extraction_configs_batch_size}张漫画图像,你需要按照以下要求从中提取对话、角色和剧情等相关信息。
===说明===
1. 输出是json格式。输出包含四个字段————"characters",表示从图像中提取的角色;"utterrances"代表从图像中提取并经过排列后的实际对话;"plot"表示当前图像集中总结的详细剧情;"chapter_start"表示从漫画中识别的‘话’分隔点。
2. 从漫画中提取全部可识别的角色(即便你无法确定名字),你需要尽可能详细的描述角色的外貌特征(发型、头饰、服装等)并为角色分配单独的索引。
3. 从漫画中提取全部的实际对话句子(排除漫画中出现的内心想法、背景文字、拟声词等非对话内容)，并根据漫画剧情的上下文推断该说话内容是由哪一角色说出的,并通过角色的索引指定"speaker"。在提取对话后，你需要合理安排对话顺序构成真实的对话。
    - [ADVICE]你可以通过气泡框初步判断该内容是否是实际对话和对应说话者。一般来说，带有*尖锐尾部*的气泡是对话且尾部指向说话者。
    - [ADVICE]可以漫画的阅读顺序初步确定对话的顺序，一般是从右向左，从上向下。
4. 在分析图像中我们可能遇到封面、目录或分隔页等非正文内容。此类内容我们不进行提取。
5. 你需要从漫画中识别‘一话’的开头位置，在图像中一般以“第{n}话 {话标题}”的形式出现。在"chapter_start"以索引的方式指出其在输入图像中的顺序(即第几张输入图像)。
6. 请从漫画内容中总结详细剧情,将人物的内心活动、动作等放到"plot"中。
===处理步骤===
(你应按照如下顺序执行提取任务)
1. 观察全部图像,从中识别‘一话’的开头位置,确定"chapter_start"。
2. 提取漫画中的角色，并为角色生成外貌特征和单独的索引。
3. 从漫画中提取实际对话，并使用1的索引指定说话者。
4. 重新排列提取的对话,形成合理的对话顺序。
5. 从漫画内容中总结剧情。
===输出格式===
{
    "characters":[
        {
            "index":"索引",
            "name":"unknown" or "漫画中可确定的人物名称",
            "description":"特征描述"
        },
    ],
    "utterances":[
        {
            "speaker":"角色对应索引",
            "content":"说话内容"
        },
    ],
    "plot":"总结的剧情",
    "chapter_start":"图像的索引,表示第几张图像开始是新的一话"
}
注:当漫画中出现可确定的角色名称时,将名字放在"name"中，无法确定名称的角色使用"unknown";"utterances"的顺序必须是经过排列的;
